
# Attention-Based LSTM for Time Series Forecasting

## 📌 Project Overview
This project implements an advanced time series forecasting model using an Attention-based LSTM network and compares its performance with a traditional SARIMAX model.

## 🔍 Features
- Synthetic time series generation with trend and multiple seasonalities
- Custom Attention-LSTM model using TensorFlow/Keras
- Rolling forecast cross-validation
- Benchmarking against SARIMAX
- Evaluation using RMSE, MAE, and MAPE
- Attention weight visualization for interpretability

## 🛠️ Technologies Used
- Python
- NumPy, Pandas
- TensorFlow / Keras
- Statsmodels
- Scikit-learn
- Matplotlib
