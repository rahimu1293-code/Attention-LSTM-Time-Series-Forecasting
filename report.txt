Advanced Time Series Forecasting using Attention‑Based LSTM

1. Introduction

Time series forecasting plays a crucial role in many real‑world applications such as finance, energy demand prediction, sales forecasting, and weather analysis. Traditional statistical models often struggle to capture complex nonlinear patterns present in modern datasets. Deep learning models, especially Long Short‑Term Memory (LSTM) networks, have shown strong performance due to their ability to model temporal dependencies.

This project focuses on building an Attention‑based LSTM model for univariate time series forecasting and benchmarking its performance against a classical statistical model (SARIMAX). The inclusion of an attention mechanism improves interpretability by identifying which past time steps contribute most to the prediction.

2. Synthetic Data Generation

2.1 Motivation

Instead of using a real‑world dataset, a synthetic time series was generated to ensure full control over underlying patterns such as trend, seasonality, and noise. This approach allows systematic evaluation of forecasting models under known conditions.

2.2 Dataset Description

A univariate time series with 2500 observations was generated programmatically using NumPy. The series consists of the following components:

Trend Component: A linear upward trend to simulate long‑term growth.

Seasonal Component 1: A short‑term sinusoidal pattern representing daily seasonality.

Seasonal Component 2: A longer sinusoidal cycle representing weekly seasonality.

Gaussian Noise: Random noise added to mimic real‑world uncertainty.

3. Data Preprocessing

Before training the models, the data was preprocessed as follows:

Normalization: Min‑Max scaling was applied to rescale the values between 0 and 1. This is essential for stable and efficient LSTM training.

Sequence Creation: A sliding window approach was used, where the previous 30 time steps were used to predict the next value.

Train‑Test Split: The dataset was split chronologically into 80% training data and 20% test data to preserve temporal order.

4. Attention‑Based LSTM Model

4.1 LSTM Overview

LSTM networks are a type of recurrent neural network designed to overcome the vanishing gradient problem. They are well‑suited for time series data because they can learn long‑term dependencies.

4.2 Attention Mechanism

While standard LSTMs treat all past time steps equally, the attention mechanism allows the model to assign different importance weights to different time steps.

In this project, a custom attention layer was implemented using Keras. The attention layer:

Computes a score for each hidden state output by the LSTM

Applies a softmax function to obtain attention weights

Produces a context vector as a weighted sum of hidden states

This context vector is then passed to a dense layer for final prediction.

4.3 Model Architecture

The Attention‑LSTM architecture consists of:

Input layer (30 time steps)

LSTM layer with tunable number of units

Custom attention layer

Dense output layer

The model was trained using the Adam optimizer and Mean Squared Error (MSE) loss function.

5. Hyperparameter Tuning and Cross‑Validation

5.1 Rolling Forecast Origin

Traditional k‑fold cross‑validation is not suitable for time series data. Therefore, a rolling forecast origin strategy was used to maintain temporal ordering.

5.2 Tuned Hyperparameters

The following hyperparameters were tuned:

Learning rate (0.001, 0.0005)

Number of LSTM units (32, 64)

The model configuration yielding the lowest RMSE on the validation set was selected as the final Attention‑LSTM model.

6. Benchmark Model: SARIMAX

To provide a baseline comparison, a Seasonal AutoRegressive Integrated Moving Average with eXogenous variables (SARIMAX) model was implemented.

6.1 Model Configuration

The SARIMAX model used the following parameters:

Non‑seasonal order: (2, 1, 2)

Seasonal order: (1, 1, 1, 24)

This model is capable of capturing linear trend and seasonal patterns, making it a strong traditional benchmark.

7. Evaluation Metrics

Both models were evaluated on a held‑out test set using standard forecasting metrics:

RMSE (Root Mean Squared Error): Measures overall prediction error magnitude

MAE (Mean Absolute Error): Measures average absolute error

MAPE (Mean Absolute Percentage Error): Measures relative percentage error

9. Attention Weight Interpretation

The attention weights were visualized for selected test samples. The visualization revealed that:

Recent time steps generally received higher attention weights

Certain periodic lags corresponding to seasonal patterns were also emphasized

This demonstrates that the model learns meaningful temporal importance, improving interpretability compared to standard LSTM models.

10. Conclusion

This project successfully demonstrated the application of an Attention‑based LSTM model for time series forecasting. By generating a controlled synthetic dataset, implementing a custom attention mechanism, and benchmarking against a classical SARIMAX model, the study highlights both performance gains and interpretability benefits.

The Attention‑LSTM model achieved superior forecasting accuracy, while attention visualization provided insights into the temporal structure of the data. This approach is well‑suited for complex real‑world time series forecasting problems.
